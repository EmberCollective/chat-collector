# 渠道层

渠道将标准投递包呈现为卡片、页面或日历事件，处理上传、回执与平台回调。任务判断、提醒策略和正式状态由上层管理。

| 目标 | 文档 |
| --- | --- |
| 配置飞书、Notion、Notion Calendar | [渠道配置](configuration.md) |
| 创建飞书应用、群与权限 | [飞书配置](feishu-setup.md) |
| 面板管理、测试发送与回调 | [渠道管理](management.md) |
| 新增渠道类型 | [渠道开发与投递信封](development.md) |

投递与反馈的数据边界见 [信息调度契约](../dispatch/contract.md)。连接测试会按用户选择执行外部发送，不能当成纯读取检查。

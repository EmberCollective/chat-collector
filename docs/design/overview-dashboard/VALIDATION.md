## 复验方式

使用本机已有 Playwright 与 Chrome，不向项目安装依赖：

```powershell
$env:PLAYWRIGHT_MODULE = '<本机 playwright 模块绝对路径>'
node docs/design/console-redesign/verify.cjs
node docs/design/overview-dashboard/verify.cjs
node docs/design/overview-dashboard/verify-acceptance.cjs
git diff --check
```

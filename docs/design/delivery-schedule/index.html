优先级截止前提醒

仅日期的截止时间，按任务时区当天 23:59:59 补足。错过多个节点只检查最近一个；该节点已被成功通知覆盖则不再重复提醒。截止提醒与普通间隔提醒不叠加。

无截止日期：按间隔提醒

完成、取消或被替代后不再催办；延后期间暂停；等待反馈回写或结果未知时停止相关投递。结果未知需先核对，不直接重发。同步型目标只同步变更，不发送周期催办。

每天 08:00：发送当日通知安排

上海时区，允许补发至当日 14:00。汇总生成时已知、当天有通知安排且未结束、未被反馈阻塞的待办；不把全部任务或只按“今天到期”当成早报范围。

早报每个目标每天一份；未来日期预览不是已排队消息。关机、休眠或后台停止时不会发送，超过补发窗口不再补当日早报。

数据口径

正式功能拟组合处理层待办、消息层 tasks / local_state / deliveries，以及既有首次通知、截止提醒、普通间隔与早报配置。本稿所有待办、目标、回执及时间均为合成数据，没有调用接口或新建调度规则。

# 运行面板统一设计：已批准参考稿

用户已批准迁移。静态稿作为合成数据设计基准保留；真实实现、测试层级及本机部署结果见 [实现验收记录](IMPLEMENTATION.md)。

打开 [静态面板](index.html#overview)，直接在负载图上移动鼠标查看同一时刻的 CPU、硬盘繁忙度及读／写速度，附本程序 CPU 与进程组归属。触屏点按／横向拖动；键盘聚焦图表后用方向键、Home／End 查看，Escape 收起。无额外滑块、锁定或播放控件。

本轮保留拾序原 Logo、字体、品牌绿、主导航和业务功能，按同一套“错误 → 运行与计划 → 质量与产出 → 按需诊断”层次整理概览与新增负载区。具体的取舍、七个视图的审查和同行资料见 [设计依据与删除清单](DESIGN.md)。

- 系统运行情况列出各来源和待办处理的下次执行日期／时刻，统一上海时区；执行中、停止、关闭与未知分别说明，不推算下轮。
- 成功率与系统卡片统一标题高度、分隔线和底边；趋势图随可用空间绘制，文字不随图缩放。点击“口径与来源”打开已有指标说明，不增加第二份说明面板。
- 负载只常驻 CPU、所选 HDD 繁忙度与读写速度。图内提示随指针移动，繁忙度紧邻同刻读／写；当前值始终为最新采样，不随查看历史改写。
- 模块进程表和采样口径合到一个按需展开入口，逐项列明模块，共用后台合计只计一次；共享模块显示无法拆分，独立进程显示 CPU／读／写。未确认的新来源不认领进程、不补 0。
- 大演示横幅、重复异常／服务 KPI、独立采样读数与重复口径提示已移除。场景选择集中在页头“预览场景”。后续按用户确认稿，把正式采集与 AI 处理区间直接叠加到负载图中，悬停查看任务名称和起止时间；投递、回写不进入该视图。草稿见 [task-nodes-draft.html](task-nodes-draft.html)。

本目录 HTML 的全部数字仍为静态合成数据，无 HTTP 请求、探针或业务写入。顶栏统一标记“静态草稿 · 合成数据”；预览场景不是正式产品设置。真实实现使用后端统计与实际探针，已移除场景控件。

成功率的正式数据入口是 `GET /api/overview?hours=24`：汇总自动化 SQLite 的 `runs`／`run_attempts` 和控制台任务 `job.json`／`result.json`，通过 `automation_run_id` 去重，不从文本日志猜测。计算为成功 ÷（成功 + 失败）；只统计窗口内开始、可确认有效结束的正式采集，重试按任务轮次计，跳过／未知／执行中不进入分母。趋势按开始时间每 2 小时分组；无样本留空。自动化每模块保留最多 1000 个终态轮次，控制台最多读取 2000 条；截断或记录不可读时不能声称全量历史。本稿的 98.6% 为合成的 69／70，末段 85.7% 为 6／7，与真实运行分开。

正式探针现随控制台服务每 5 秒自动采样，关闭浏览器仍保留最近 60 秒内存记录，不落库、不持续追栈。静态稿保留原审批时的展示文字，不运行真实探针。进程独立时可归属；自动化的多个模块共用进程，只提供共享合计。进程 I/O 含缓存与其他磁盘，与物理盘读写不能直接对账。首次／恢复需建立计数基线，短任务可能漏采，不能把采样最大值当精确峰值。

审批前的性能定位与方案见 [性能报告](PERFORMANCE-PLAN.md)。用户现场完整主页约 6000 毫秒是定位基线，实施后的本机测量与首次采样等待另记于实现验收，不用静态稿速度代替真实测量。

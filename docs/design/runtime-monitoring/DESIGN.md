# 统一设计依据与删减记录

本稿为已批准的设计基准；HTML 保持合成数据，不连接真实后台。迁移结果见 [实现验收](IMPLEMENTATION.md)。设计依据是本产品的实际任务、已有批准稿、当前代码事实与可核对的产品文档；没有做真实用户研究，不把原则称为已证明适用于所有人的定律。

## 五条方向

- 产品：供用户查看本地信息整理自动化是否完成工作，并从异常追查具体运行。
- 性格：克制、准确、可追查。
- 场景：日常工作台与运行仪表；沿用已有中性底色、品牌绿和原 Logo。
- 视觉重点：错误、趋势和实际产出承担注意力；界面外壳保持安静。
- 一致细节：问题始终通向相关运行与配置，返回时保留来源和筛选。

## 可检查的设计原则

1. 每个常驻元素必须回答用户当前的问题：哪里出错、现在做什么、何时再执行、产出与质量如何。参数解释、进程明细只在用户要求时展开。
2. 同一事实有一个主要位置。异常留在顶部问题区；后台状态留在系统区；CPU／磁盘当前值留在负载摘要。历史细项可用于验证摘要，但不再重复铺设状态 KPI。
3. 直接在对象上操作。趋势图内查看读数，异常点打开对应运行；配置动作贴近来源／任务；不在图外另加一个“操纵图表”的区域。
4. 先摘要、后证据。自动化按工作环节分类，运行记录按操作／模块／触发／耗时筛选；日志与 Pi 正文按需展开。此为界面层次，真实加载优化仍待审批。
5. 事实和未知分开。进程运行中不等于任务成功；共用进程不冒充模块独占；缺测与关闭不写 0；计划时间不当作保证开工时间。
6. 延续已批准的组件：桌面 224px 导航、64px 顶栏、内容侧边距 32px；紧凑控件以 36px 为主，原表单控件 40px；卡片内边距 16／20／24px，4px 节奏，原字体与 400／500／600 字重。新增区域不建立另一套样式。

## 审查发现及删除依据

| 原位置／现象 | 本轮处理 | 理由 |
|---|---|---|
| 图下 range 滑块、查看采样点标签、独立读数栏 | 删除，改为图内跟随游标／同刻提示 | 查看目标与操作对象分离，且鼠标交互本已能完成相同任务 |
| 负载图下两条任务时间轨 | 删除；当前任务保留在标题副行，同刻任务在图内提示 | 对本页简短 60 秒诊断重复描述任务，挤占图表；未新增回放功能 |
| 默认展开 5 行进程表，另起一组口径说明 | 合成“模块占用与采样口径”折叠区 | 日常先判断负载，需要归属时再查询；保留全部字段与未知边界 |
| 大绿色草稿横幅、侧栏／页底反复标记演示 | 顶栏统一合成数据标记；场景集中页头一个入口 | 原型工具不成为产品的信息层级，不反复占用纵向空间 |
| 概览 KPI 再次显示异常数量和后台运行 | 去掉，保留入库变更、成功率、平均采集耗时 | 异常区与系统区已有同一事实；补回用户需要的时间成本 |
| “正常无异常”仍常驻一个空问题面板 | 正常时隐藏；首次无数据说明保留 | 没有待办不要求用户处理一块空区域，首次缺少数据仍需解释 |
| 成功率标题副文案与右侧“正式采集”重复 | 合成一行范围说明 | 同一图表范围重复，无新增信息 |
| 成功率与系统卡片标题分隔线、底边错位 | 同排卡片统一 88px 标题区、底边对齐；曲线按实际空间绘制 | 以共同边界组织同级信息，不靠拉伸 SVG 文字或填空白假对齐；窄屏恢复自然堆叠 |
| 成功率说明仍暗示尚无正式统计来源 | 改为已核对的接口、结构化来源、公式和历史覆盖边界；图上入口打开原说明 | 区分现有真实统计与本稿的固定样例，避免重复说明区域 |
| 图内仅有 CPU／繁忙度，缺少读／写和归属 | 同时刻展示物理盘读写、本程序 CPU 与后台／监听／控制台组 | 读写是独立样本，不能由繁忙度换算，也不能把最新速度填进历史点 |
| 模块筛选只见“共享后台”，未逐项列出模块 | 共享合计下逐项列模块，独立进程另列 | 让归属可查，同时承认探针不能拆分共用进程；不得给五个模块各复制同一个总量 |
| 每条下次计划同时铺绝对时刻与大段倒计时 | 保留完整日期和时刻；执行中独立说明 | 满足具体时间需求，避免每行重复解释同一时间值 |
| 负载正常时仍铺“采样正常”状态条 | 正常不显示；中断／不可用时按需出现 | 用户需要介入或解释缺口时才提升状态提示 |
| 各页原有统一的导航、按钮、表单和行操作 | 保留，补齐一致焦点样式 | 已符合任务路径与品牌，避免无依据改动成熟页面 |

平均采集耗时为静态样例，按 36×18.4 秒与 34×42.6 秒加权，70 个有效结束轮次得到 30.2 秒；不是用各来源 P95 求平均，也不是正式指标接入。

## 七个视图逐一审查

| 视图 | 保留 | 调整／统一 | 按需出现与边界 |
|---|---|---|---|
| 运行概览 | 错误优先、成功率、来源贡献／存储切换、采集表现、错误下钻 | 三项摘要；系统区显示下一次时刻；负载图内查看；删重复状态与原型横幅 | 模块进程表／口径折叠；正常空异常区隐藏；未知与缺测明示 |
| 信息源调试 | 单一来源选择、筛选预览／消息浏览、SQL 规则与附件检查、原检查器布局 | 沿用同一 36／40px 控件和焦点；来源操作仍贴近来源，设置快捷入口指向统一配置 | 外部管理来源保留只读能力边界；不在此页另建自动化编辑器 |
| 待办处理／Pi | 工作流、上下文、工具参数／返回、可见模型输出、任务详情 | 保留既有信息次序，执行状态与业务结果分别标明；详情沿用运行记录样式 | 长正文与原始事件折叠查看；历史未记录正文不补造；不把初始上下文当完整请求 |
| 行动与投递 | 待办／投递记录、操作回写、未知结果先核对 | 操作贴近对应记录；核实后的结果在概览／运行记录同步 | 未核对前重试禁用；已安排不冒充送达；没有排队操作时保留必要的状态说明 |
| 自动化 | 采集与处理、投递与提醒、后台服务三类；发现 SQL 规则、统一保存 | 保留按工作环节分类与一个统一保存入口；不把新负载探针扩张成新配置中心 | 规则与高级字段按任务展开；外部管理来源不伪造可控计划；保存边界不变 |
| 运行记录 | 操作／模块／触发／耗时／结果筛选与排序，相关运行详情、返回原范围 | 同一条记录在概览图点、来源问题、历史列表都打开同一详情路径 | 日志／上下文按需看；不在每条历史复制完整资源表；未采集的历史负载不补造 |
| 设置 | 来源配置与模型配置、已知字段描述、版本与未保存编辑 | 继续承载字段编辑；自动化快捷入口跳转既有位置，避免同一设置两处编辑 | 源能力决定可编辑字段，未知字段保留；凭据只显示本机引用，不向展示稿填真实信息 |

上述七页全部保留在一个静态 HTML。修改重心是概览与新增诊断，已批准且符合原则的业务页主体保留；本轮不是新增七套布局。内部检查实际切换七个主导航，未知投递必须核实的恢复路径仍可操作。

## 图表交互细则

- 默认仅显示曲线和坐标。鼠标移入后，同一采样时刻的 CPU、硬盘繁忙度及紧邻的读／写速度在图内提示，并列本程序 CPU 与后台／监听／控制台占用；离开收起。任务文本只表示同时发生，不将整盘繁忙度归因给任务。
- 触屏首次点按按接触位置选点，横向拖动使用同一选点逻辑；保留 `touch-action: pan-y`，不阻止纵向滚页。点其他区域收起。
- 键盘焦点就在图表；左右、Home／End 与指针共用同一选点函数，Escape 收起，不增加另一套控件。
- 鼠标移动只改游标、两枚点和提示节点，不重画 SVG、不请求数据、不触发逐点读屏播报。读屏仅对键盘选择播报。
- 当前值始终表示最近采样。查看过去不会改掉当前值；缺测区显示未知并保留曲线缺口。
- 不加入锁定、播放、缩放、回放或多种图表模式；现有任务不需要这些设施。
- 成功率图沿用已有图内读数与失败点直达记录；其 24 小时聚合与负载的 60 秒窗口各自标清，不强行同步时间范围。
- 负载明细表始终是最新采样，不随历史悬停改写，并标明时间。微信、QQ、待办处理、投递、回写逐项列出，“—”配合无法拆分说明；共享合计只算一次。已停止的业务进程不计占用，控制台可继续采样，不再错误显示后台停止后仍合计 0.7%。
- 已核对 `tools/console/overview.py` 与正式前端：成功率来自 `/api/overview` 汇总的自动化运行 SQLite 与控制台结构化任务／结果文件，不是模型 API 成功率或文本日志解析。有效结束与采集结果均需可确认，重试为同一任务轮次；按开始时间归入 2 小时桶。缺失、截断与无样本均不能伪装成完整统计。本稿 69／70 和末桶 6／7 是固定合成示例。

## 内部验收范围

检查生成一致性、同排卡片顶部／底部／标题分隔线对齐、成功率来源入口、七种运行／采样状态、两块示例盘、同刻读写而非复用末值、鼠标跟随且 SVG 不重建、首次真实触屏点按、键盘首末与收起、当前值不被 hover 改写、鼠标不触发读屏广播、共享模块逐项明示但不重复分配用量、新来源未知归属、投递先核实流程、七个导航视图、320–1600px、无 HTTP 请求／脚本错误。桌面默认负载区由原约 1350px 压到约 475px；展开诊断后内容按需增长。

未进行真实用户测试、真实探针校准或性能迁移。静态稿的合成数据和样例进程只用于评审；不影响正在运行的采集、处理、投递。

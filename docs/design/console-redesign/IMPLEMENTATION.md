# 调试台改版实现与内部验收

用户已批准统一静态方案。本轮正式实现位于 `tools/console`，运行概览与自动化三分类已经迁移；独立静态稿继续作为视觉基线。现有安装包实例没有替换。

运行概览读取认证的 `/api/overview?hours=24`，汇总保留的采集轮次、真实故障、服务和队列、项目文件逻辑大小。重试尝试不混入轮次分母；等待刷新、未启用规则、未完成与结果未知分别呈现。历史重放不能恢复正式采集故障，缺少结束时间的未知结果仍可进入问题列表。来源通过配置路径关联实例，统计缺失不补 0。

正式页面沿用批准稿的结构和独立样式，自动化分为“采集与处理 / 投递与提醒 / 后台服务”。来源和处理的低频重试项收进面板标题的高级设置，全部配置与原有操作保留。统一保存前校验并定位隐藏非法字段，保存中锁定输入，版本冲突保留草稿。SQL 继续移动复用同一编辑器。

错误、失败趋势点和轮次色条共用实际运行详情，进入配置后可返回原范围；历史页接续模块、操作、时间和结果筛选。未知投递必须核实后才可确认或重试，恢复期间互斥禁用按钮，迟到响应不污染另一个运行详情。没有来源映射的旧记录不能借用当前来源或处理任务执行。

概览由三份源片段生成到单文件 HTML，旧独立入口只跳转，不再维护另一套界面。主工作区已通过生成一致性及三套浏览器检查；桌面、手机与恢复对话框已目视核对。详细路径、口径和未测范围见[专项验证记录](../overview-dashboard/VALIDATION.md)。

## 已实现

- 七个目标入口，包含独立的“自动化”；信息源条件、消息与证据同屏。窄屏导航使背景不可操作，消息详情使用原生对话框；支持键盘页签。
- 名称与图形沿用根 README 的“拾序 · Loose Ends”，控制台图标复制原 SVG 几何，文档和两份静态稿使用同一品牌。
- 服务端来源目录区分实例 ID 与类型；同类型可配置多个实例。前端按能力显示并检查操作，服务端复核。未知来源只读，没有动态代码加载器。
- 渠道字段、名称、默认值和能力从服务端生成；未知目标及未编辑字段保留，不能发送测试。新增目标默认关闭。
- Pi 详细正文与轻量进度分开；记录初始输入、实际请求（含原生压缩请求）、可见输出、工具参数 / 结果、压缩摘要、重试及结果。面板、后台与命令行共用本机受认证的持久化查看入口。
- 运行记录支持模块、操作、触发方式、状态、时间、耗时及错误内容组合筛选，耗时排序、分页与历史详情，不受最近 30 / 100 条内存列表限制。
- 已合并远程 `origin/main` 的统一后台和执行历史（合并提交 `08c6411`），移除旧控制台调度器。自动化集中展示任务、通道与提醒、SQL 采集规则；任务名称和来源绑定读取实际配置，按配置路径匹配来源实例。
- SQL 规则从项目 `rulesets/` 及已注册规则的父目录发现，通过 SQLite 只读编译识别实际参数。新文件默认未注册、未启用；原路径、缺失文件和未知参数保留。信息源与自动化共用一个规则编辑器和按来源保存的草稿，仍由现有配置版本检查和备份机制保存。
- 信息源异常和后台任务错误可点击查看相关记录、错误位置、日志及配置。后台处理轮次关联每次尝试的 Pi 详细记录，运行列表避免重复显示同一轮次；旧记录无法补造的正文仍明确缺失。
- 保留原配置版本检查与备份、预览七天限制、重放不受七天限制、附件下载与来源证据、调试结果隔离、规则编辑、回写 / 未知投递恢复以及后台设置。

## 审查与提交边界

来源目录、Pi 详细记录、后台记录、持久化历史分别为独立提交。前端迁移需要协调 HTML、样式、脚本及浏览器验收，作为一次完整迁移交付，超过技能建议的 1000 行：仅可读格式样式就有 1164 行。此为明确的范围例外，未以压缩代码隐藏规模。原静态稿和首页扩展包含生成的内嵌样式 / SVG 与截图，另按设计产物保存。

两轮独立只读复核发现并修复了来源草稿串用、保存覆盖另一来源、异步预览串用、Pi 选择错标、重复元素编号、历史加载失效，以及引号内凭据脱敏遗漏；对应确定性检查已加入。未自动修改技能规则。

当前环境未提供原生 Codex Code Review / Security Review 入口，仓库没有相应工作流配置；只读代理复核不冒称原生审查。未推送、发布或合并到主分支。合并前已保存原工作区快照；旧代码中被远程新版覆盖的实现没有重复恢复，本机 `Start.cmd`、`config/automation.toml`、`config/messaging.toml` 的原有修改保留。

## 限制

未用真实模型、正式采集或外部投递做联调，未做安装发布和完整屏幕阅读器验收。现有安装包实例没有替换，功能预览使用合成数据。

旧运行没有保存的 Pi 正文无法补造；图片编码、隐藏推理与超限正文不会完整保存。详细记录含本地聊天与附件文字，应按业务数据管理。若后台成功后最终元数据写入失败，待办仍会保存，但长驻进程中的状态可能暂时显示执行中，程序会发出记录故障提示。

原生附件提供器目前每个平台配置一份采集来源；多账号采集控制与证据路由已区分实例，不代表跨账号附件准备已经扩展。新增主页已汇总现有轮次与队列记录。空间测量限明确配置路径，缓存 60 秒、每次最多 2 万条 / 0.5 秒，硬链接去重并单列共享；物理占用未测量，截断和不可读明确标记。

返工总结已单独完成：后续规则候选是为异步操作固定实体与请求代次、禁止保存完成后重载其他实体的表单，以及用真实执行路径验证记录覆盖（压缩与后台都要覆盖）。只记录候选，不自动改技能规则。

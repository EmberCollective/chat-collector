# Windows 安装包验收

交付结论：**Windows x64 本地使用预览**。已实际安装私有运行环境并验证后台启动、重复启动、停止和调试台；新账号授权、首次取钥、首次 7 日模型处理的完整在线流程尚未实测，不称为正式发行版。

## 测试范围

| 层级 | 结果 | 覆盖内容与限制 |
|---|---|---|
| 单元与模拟流程 | 通过 | 安装模板、固定 7 日时间窗、分批处理直到清空、失败断点、已有部署不覆盖、无进展时停止、配置校验失败保留原文件；面板鉴权、严格参数和自启失败反馈 |
| 隔离运行环境 | 通过 | 从实际 ZIP 解压后执行 `install.ps1 -PrepareOnly`；私有 Python 3.13.8、49 项哈希锁定依赖、原生 SQLCipher/变化页扩展、wx_key、Node 和 Pi 安装与加载；再次运行跳过已安装依赖 |
| 原生回归 | 通过 | 使用私有 Python 执行微信/QQ 增量、原生变化页、飞书及安装/面板测试；不访问真实聊天客户端或模型 |
| 后台服务 | 通过 | 在独立目录、独立端口启动安装包启动器；重复启动复用同一服务和面板 PID，停止后确认隔离进程退出。所有业务任务关闭，不代表真实账号采集成功 |
| Windows 启动项 | 通过 | 临时目录下创建、查询、重复设置、模拟任务管理器禁用、重新启用、执行隐藏命令并删除；仅修改该测试条目。正式安装自启保持关闭 |
| 实际浏览器界面 | 通过 | 本机面板显示真实“未开启”状态；桌面及 390 像素宽度检查，按钮可用，无页面脚本错误，无页面横向溢出；未点击正式部署的启用按钮 |
| 新账号在线流程 | 未测 | 新微信/QQ 账号取钥、客户端版本兼容、首次真实 7 日模型处理、新飞书应用注册与发布、首次回调闭环 |
| 开机与重新登录 | 未测 | 已验证注册表条目和隐藏命令执行，未实际重启 Windows 或注销登录；机器休眠/关机期间不运行 |
| 其他平台 | 不适用 | 当前包仅 Windows x64；未提供 macOS、Linux 或 Windows ARM 安装器 |

`PrepareOnly` 只准备和检查依赖，不伪造首次配置成功。服务验收使用合成配置，不填账号或模型凭据；已有部署的自动化服务与业务配置保持原状。

## 产物与证据

构建产物为 `dist/chat-collector-windows-x64-preview.zip`。同目录 `.zip.sha256` 是最终文件校验值；包内 `release-manifest.json` 记录源码提交、构建时工作区状态和逐文件校验值。`dist/installation-acceptance.json` 将最终 ZIP 校验值、源码提交与测试结果关联，避免把旧包结果当成新包结果。

本地验收保留安装日志、测试日志、服务启动结果和桌面/窄屏截图。它们不随产品源码打包，不含密钥。包采用明确的源文件目录清单，排除真实配置、`.env`、数据库、导出聊天、运行记录和已安装的 Node 依赖；再使用独立默认模板完成首次配置。

验收修复了嵌入式 Python 不自动包含项目及脚本目录导致的后台模块加载问题，新增子进程导入检查，实际后台启动通过后才交付。

## 使用边界

- 新账号取钥需要客户端登录及明确的管理员授权；微信数据库密钥不能替代图片密钥。图片和旧版 Word 的限制见 [安装指南](installation.md#微信与-qq-取钥)。
- 模型和飞书在线能力需用户完成有效配置。服务进程“运行中”不能代替每个任务、长连接及投递回执的成功状态。
- 本次不覆盖升级现有部署，不改变正式自启选择，不为打包重复消费真实 7 日模型额度。
- 公开再分发前仍需核实上游微信来源文件许可；当前包仅用于本地验收。

SQL 规则集

每个 .sql 文件独立查询同一份本轮消息，结果取并集并去重，再处理附件和输出。群聊、关键词、文件和 @所有人都在 SQL 中定义。此处修改只用于预览，正式采集和重放使用已保存的规则集。

例如：[{"file":"../rulesets/keyword.sql","params":{"keyword":"截止"}}]。路径相对模块配置文件。各项 enabled 为 true 时启用、false 时关闭，省略表示启用；空数组或全部关闭时不采集、不推进时间记录。all.sql 表示选取全部消息。

关键词只匹配当条正文。上下文独立注册：{"file":"../rulesets/context.sql","enabled":true,"recent_count":5}，以 @所有人或文件为中心，带出同会话前后各 5 条，包含中心。前文可跨出本轮起点；尚未到达的后文在后续轮次继续匹配。

模块配置

保存后影响后续轮次，不回看历史。更改存储目录不会移动已有数据；账号和状态库在此只读。

扫描间隔是每轮结束后的等待时间。数据库刷新间隔由你填写，0 表示每轮；未到刷新时间会暂缓整轮，不推进消息断点，手动重放立即刷新。轻量只保留附件元数据；标准归档本地文件、微信密文并复用可读图片缓存；完整额外尝试微信图片解密与转换。三档均保留全部匹配消息。关闭“保存附件”时不执行归档或解码。降低强度后重放可能使最新修订只剩元数据；历史批次和已存文件仍保留，需用完整档重放补齐。

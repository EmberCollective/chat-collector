上下文筛选

在同一会话中，当前消息或其前后 N 条有任一条命中条件，就选中当前消息。上下文可跨出时间范围，但只输出范围内消息；尚未到达的后续消息需日后重放补查。上方基础条件仍限制当前消息。

数组内各规则与基础条件同时成立。删除规则可编辑数组；清空为 [] 表示只使用基础筛选。多个备选条件可使用 any，全部条件使用 all。

预览只读；重放可能补充附件并产生消息修订。

模块配置

保存后影响后续轮次，不回看历史。更改存储目录不会移动已有数据；账号、状态库和代码扩展入口在此只读。

扫描间隔是每轮结束后的等待时间。数据库刷新间隔由你填写，0 表示每轮；未到刷新时间会暂缓整轮，不推进消息断点，手动重放立即刷新。轻量只保留附件元数据；标准归档本地文件、微信密文并复用可读图片缓存；完整额外尝试微信图片解密与转换。三档均保留全部匹配消息。关闭“保存附件”时不执行归档或解码。降低强度后重放可能使最新修订只剩元数据；历史批次和已存文件仍保留，需用完整档重放补齐。
